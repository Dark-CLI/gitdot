# Default Dark Theme for Yazi

This theme matches your Neovim `default-dark` colorscheme.

## Colors Used

| Component | Color | Hex |
|-----------|-------|-----|
| Background | Black | #181818 |
| Foreground | White | #f8f8f8 |
| Primary Accent (Blue) | - | #7cafc2 |
| Secondary Accent (Cyan) | - | #86c1b9 |
| Success (Green) | - | #a1b56c |
| Error (Red) | - | #ab4642 |
| Warning (Yellow) | - | #f7ca88 |
| Info (Purple) | - | #ba8baf |

## Usage

The theme is automatically activated when `flavor = "default-dark"` is set in `yazi.toml`.
